# 📊 Relatório de Análise: Estatísticas de Futebol (Champions League)

## 🎯 Objetivo do Projeto
O objetivo deste projeto acadêmico de portfólio é analisar as estatísticas ofensivas e defensivas de 5 grandes clubes na **UEFA Champions League** (Manchester City, Bayern de Munique, Real Madrid, PSG e Inter de Milão). A partir dos dados de jogos, gols marcados e gols sofridos, o projeto busca estruturar as informações e calcular a métrica de **Média de Gols por Jogo** para avaliar a eficiência de cada equipe no torneio.

## 🛠️ Tecnologias Utilizadas
* **Google Colab:** Ambiente em nuvem utilizado para execução dos scripts e documentação do projeto.
* **Python 3:** Linguagem de programação aplicada no desenvolvimento da análise.
* **Pandas:** Biblioteca do Python utilizada para a criação da estrutura de dados (`DataFrame`), manipulação numérica e cálculo da coluna derivada de média de gols por partida (`round(2)`).

## 🧠 O que foi Aprendido com a Experiência
A partir da elaboração deste projeto, foi possível consolidar os seguintes conhecimentos práticos:
* **Estruturação de Dados com Dicionários:** Criação e organização de coleções de dados nativas do Python para posterior conversão em tabelas.
* **Uso da Biblioteca Pandas:** Aprendizado sobre a criação de `DataFrames` e manipulação de colunas operacionais (divisão entre `Gols_Marcados` e `Jogos`).
* **Arredondamento e Formatação:** Aplicação do método `.round(2)` para padronizar os resultados decimais da média de gols.
* **Geração de Insights Esportivos:** Identificação do clube de maior eficiência ofensiva no período analisado (Manchester City, com média de 3.00 gols/jogo).
